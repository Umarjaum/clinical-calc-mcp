# Changelog

Notable user-facing changes are recorded here. This project follows semantic versioning after its initial release.

## 0.2.0 — Expanded tools and client setup

- Add validated calculations for pulse pressure, estimated MAP, and un-interpreted shock index.
- Add Celsius/Fahrenheit and kilogram/pound conversion tools.
- Add dedicated setup instructions for Claude Desktop, Cursor, VS Code, and other local stdio MCP clients.
- Expand safety documentation with cited limitations for estimated MAP and shock index.
- Improve repository discovery metadata and community participation.

## 0.1.0 — Initial release

- Add FastMCP tools for the classic Parkland formula, Mosteller BSA/BMI, and infusion drip rates.
- Add finite, positive, and range validation with explicit units and errors.
- Add deterministic rounding, clinical safety notices, and local-only security model.
- Add pip/uv packaging, console entrypoint, tests, documentation, and CI.
